Rental Flow · team226

개인정보처리방침

시행일 2026년 10월 23일

team226(이하 “운영자”)은 Rental Flow에서 처리하는 개인정보의 항목, 목적, 저장 방식과 이용자의 권리를 안내합니다. 개인정보 문의 및 권리 행사: contact@rentalflow.example.

1. 처리하는 정보와 목적

  • Google 계정 정보: Google 로그인 과정에서 제공되는 계정 식별자, 이름과 이메일 주소. 로그인, 계정 식별과 기기 안 업무 데이터의 계정별 구분에 사용합니다. Rental Flow는 Google 비밀번호를 받거나 저장하지 않습니다.
  • 렌탈 업무 정보: 사용자가 입력하는 사업장, 상품과 그룹, 예약, 업무 기록, 문제, 고객 이름과 연락처, 메모, 서명, 금액 및 체크리스트 응답. 예약 관리, 대여·반납 업무 수행과 이력 확인에 사용합니다.
  • 사진: 사용자가 촬영하거나 선택한 업무 사진 원본. 해당 기기의 앱 저장공간에 보관하며, 업무 기록에는 사진을 연결하기 위한 기기 내부 식별자가 저장될 수 있습니다.
  • 기기 캘린더 연동(선택): 사용자가 설정에서 캘린더를 직접 선택할 때 기기 캘린더 읽기·쓰기 권한을 요청합니다. 현재 예약 일괄 연동 또는 신규 예약 자동 연동을 사용하면 선택한 캘린더에 예약 일정(물품명과 예약 참조 번호로 된 일정 제목, 시작·종료 시각)을 만들거나 변경·삭제합니다. 중복 방지와 앱이 만든 일정의 갱신·삭제를 위해 앱이 만든 일정의 표식만 조회하며, 다른 일정의 내용은 읽지 않습니다. 고객 이름, 연락처, 메모, 금액은 캘린더로 보내지 않습니다.

렌탈 업무 정보와 사진 원본은 이 기기에 저장되며 운영자 서버로 전송되지 않습니다. 사용자가 현재 예약 일괄 연동을 실행하거나 신규 예약 자동 연동을 켜면 예약 일정 정보(물품명과 예약 참조 번호로 된 일정 제목, 시작·종료 시각)가 선택한 캘린더로 전달되어, 기기 계정 설정에 따라 캘린더 제공자(예: Google)의 서버에 동기화될 수 있습니다. 신규 예약 자동 연동은 기본적으로 꺼져 있으며, 현재 예약 일괄 연동은 별도로 실행할 수 있습니다. 서버 데이터베이스 저장, 중앙 백업, 원격 오류 수집과 푸시 알림 토큰 등록을 하지 않습니다. 광고 SDK, 광고 식별자 기반 추적, 위치 추적도 사용하지 않습니다. 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다.

2. 외부 전송

기기를 떠나는 개인정보는 기본적으로 Google 로그인에 필요한 계정 정보입니다. 로그인할 때 Google 계정 정보와 인증 토큰이 Google의 Firebase Authentication으로 전송됩니다. 사용자가 현재 예약 일괄 연동을 실행하거나 신규 예약 자동 연동을 켠 경우에는 예약 일정 정보(물품명과 예약 참조 번호로 된 일정 제목, 시작·종료 시각)가 선택한 캘린더로 전달되어 캘린더 제공자의 서버에 동기화될 수 있습니다.

국외 이전

  • 이전받는 자: Google LLC. 이전 국가: 미국 등 Google이 서비스를 운영하는 국가. 이전 항목: 계정 식별자, 이름과 이메일 주소, 인증 토큰. 이전 시점과 방법: 로그인과 세션 갱신 시 네트워크를 통해 전송. 이전 목적: Google 로그인 인증. 보유 기간: Google의 서비스별 정책에 따릅니다. 거부 방법: Google 로그인을 사용하지 않으면 로그인이 필요한 기능을 이용할 수 없습니다.

캘린더로 전달한 일정 정보는 사용자가 선택한 캘린더의 계정 설정과 해당 제공자의 정책에 따라 처리되며, 운영자는 이를 별도로 수집하거나 보관하지 않습니다.

Google은 해당 정보를 국외를 포함한 서비스 운영 지역에서 처리할 수 있으며, 보관 기간과 처리 방식에는 Google 정책이 적용됩니다. Google 개인정보처리방침 · Firebase 개인정보 안내

3. 고객 정보를 입력하는 경우

렌탈 사업자는 앱에 입력하는 고객 정보에 관해 필요한 고지와 적법한 처리 근거를 확보해야 합니다. 업무에 필요하지 않은 민감정보나 고유식별정보를 입력하지 마세요. 고객의 정보 열람·정정·삭제 요청은 해당 정보를 입력한 렌탈 사업자를 통해 처리할 수 있습니다.

4. 보관과 삭제

업무 정보와 사진은 사용자가 삭제할 때까지 해당 기기에 보관하며, 개별 기록에 일률적인 자동 만료 기간은 두지 않습니다.

  • 설정의 계정 삭제를 실행하면 Firebase Authentication의 Rental Flow 로그인 계정과 해당 기기의 업무 정보 및 사진이 함께 삭제됩니다. 사용자의 Google 계정 자체는 삭제되지 않습니다.
  • 설정의 이 기기의 데이터 삭제를 실행하면 해당 기기의 업무 정보와 사진이 삭제됩니다. Rental Flow 로그인 계정과 Google 계정은 삭제되지 않습니다.
  • 앱을 삭제하거나 앱 저장공간을 지우면 기기에 저장된 업무 정보와 사진이 사라지며 복구할 수 없습니다.
  • 신규 예약 자동 연동을 끄거나 권한을 철회해도 이미 만들어진 외부 캘린더 일정은 자동으로 삭제되지 않습니다. 앱에서 계정이나 기기 자료를 삭제해도 이미 외부 캘린더로 복사된 일정은 해당 캘린더에 남을 수 있습니다.
  • 이미 내보낸 JSON 파일은 앱의 삭제 기능으로 삭제되지 않습니다. 저장한 위치에서 사용자가 직접 관리하고 삭제해야 합니다.

운영자 서버에 업무 데이터의 사본이나 백업이 없으므로 삭제된 기기 자료를 운영자가 복구할 수 없습니다. 앱을 이용할 수 없어 계정 삭제가 필요하면 계정 삭제 안내를 확인해주세요.

5. 내보내기와 가져오기

사용자는 설정에서 업무 데이터를 JSON 파일로 내보내고 가져올 수 있습니다. 내보내기 파일의 저장 위치와 공유 대상은 사용자가 선택하며, 파일의 보관·보호·삭제와 가져오기 전 백업은 사용자 책임입니다. 사진 원본은 JSON 내보내기 파일에 포함되지 않습니다.

6. 이용자의 선택과 권리

사용자는 앱에서 입력한 업무 정보를 확인·수정·삭제할 수 있고, 설정에서 계정 또는 기기 자료를 삭제할 수 있습니다. Google 로그인 계정 정보의 처리에 관한 요청이나 앱을 사용할 수 없는 상태의 문의는 contact@rentalflow.example으로 보낼 수 있습니다. 본인 확인에 필요한 최소한의 정보를 요청할 수 있습니다. 알림과 카메라·사진 관련 접근은 기기 설정에서 변경할 수 있습니다. 캘린더 접근 권한도 기기 설정에서 철회할 수 있습니다.

7. 안전한 처리

업무 정보와 사진은 앱 전용 기기 저장공간에 보관됩니다. Android 시스템 백업과 기기 간 이전 대상에서 앱 데이터를 제외합니다. Google 로그인 통신에는 암호화된 연결을 사용합니다. 사용자는 기기 잠금과 운영체제 보안 업데이트를 유지하고, 내보낸 JSON 파일이 다른 사람에게 노출되지 않도록 관리해야 합니다.

8. 아동 및 방침 변경

Rental Flow는 렌탈 업무를 관리하는 사업자와 담당자를 위한 서비스이며 아동을 대상으로 설계되지 않았습니다. 처리 항목, 목적 또는 저장 방식 등 중요한 내용이 바뀌면 앱 또는 정책 페이지에서 변경 내용과 시행일을 안내하고 필요한 경우 별도 동의를 받습니다.
