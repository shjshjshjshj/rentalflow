Rental Flow 계정 삭제

계정 삭제는 Android 앱의 설정 → 계정 삭제에서 직접 진행합니다. 이 기능은 사용자의 Google 계정 자체를 삭제하지 않습니다.

삭제되는 정보

  • Rental Flow 로그인 계정(Firebase Authentication)
  • 이 기기에 저장된 사업장 정보, 상품과 그룹, 예약, 고객 연락처, 업무 기록과 사진
  • 등록된 대여·반납 알림과 홈 화면 위젯의 표시 내용

업무 데이터는 이 기기에만 저장되므로 삭제하면 복구할 수 없습니다. 이미 내보낸 JSON 파일은 앱의 삭제 기능으로 지워지지 않으며 저장한 위치에서 직접 삭제해야 합니다.

기기 자료만 지우려면 설정의 이 기기의 데이터 삭제를 사용하세요. 이 경우 로그인 계정과 Google 계정은 그대로 유지됩니다.

앱을 이용할 수 없다면 contact@rentalflow.example으로 계정 삭제를 요청해주세요. 본인 확인 후 처리합니다.
